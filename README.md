XG Mobile Card
==============
This open source PCIe AIC allows you to use your existing XG Mobile eGPUs with regular x86 Motherboards.

It is based on researchs and works done by [XG_Mobile_Station](https://github.com/osy/XG_Mobile_Station), shout out to them! You guys rock!  

## Features
* PCIe 3.0 x 8 PCIe connections for fast eGPU applications
* Internal USB Type-E connector for USB Hub
* More to come .......

## Known Issues
1. I only have one single GC31 unit /w RTX 3080 LP, and all my work are based on that card.   
2. I have limit access to following PCIe motherboards so you might need to test your own. They are:
    * MSI X670E Carbon WiFi
    * GIGABYTE Z890 AORUS ELITE WiFi 7
